# Never book Andries between 09:00 and 10:00 SAST

IF you would book Andries between 09:00 and 10:00 SAST, THEN do not. Use Elmien's calendar first, then Davide's.

This does not override the later rule: when a provider has already confirmed a clear day and time, book that slot on Davide's calendar.
