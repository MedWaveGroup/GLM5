# Learning log: objection and follow-up outcomes

Append one row per message set the watcher sends. Review weekly: promote variants that book, retire ones that don't, and update [[objection-playbook-1113]] / [[follow-up-cadence]].

## How to append
- `date` SAST `YYYY-MM-DD HH:MM`; `contact_id` HighLevel id (no names, phones or emails)
- `type` objection key or `touch_1..3`; `variant` index from the JSON; `channel` whatsapp/email
- `outcome` booked / replied / no_reply / opted_out / escalated; `booked_at` slot if booked; `notes` short
